# 🔥 Burn Money

> **See where your money goes.**

Burn Money is a modern personal finance dashboard that helps users track income and expenses, analyze spending habits, and manage savings goals.

## ✨ Features

* 💰 Income & expense tracking
* 📊 Interactive financial analytics
* 🎯 Savings goals with progress tracking
* 🧠 Smart spending insights
* 🔍 Search & category filtering
* 🏆 Achievement system
* 💾 LocalStorage data persistence
* 🎉 Goal completion celebrations

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Chart.js
* Canvas Confetti
* LocalStorage

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/burn-money.git
cd burn-money
```

Open `index.html` in your browser, or use VS Code Live Server.
